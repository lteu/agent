# Assets

这里保存项目的辅助材料，不作为当前产品文档或运行时依赖：

| 目录 | 内容 |
| --- | --- |
| `archive/` | 已过时的方案、历史安装记录和开发笔记 |
| `reports/` | 阶段性评审与分析报告 |
| `research/` | 专题调研和外部资料摘要 |
| `screenshots/` | 手工截图、浏览器自动化截图和页面快照 |
| `debug/` | 本地复现时留下的日志与查询结果；已由 Git 忽略 |

要了解当前行为，请从根目录 [README](../README.md) 和 [`docs/`](../docs/) 开始。
