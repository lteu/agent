## 其他运行入口

| 命令 | 用途 | 前置条件或文档 |
| --- | --- | --- |
| `ai-cc` | 在隔离 Docker 环境中运行官方 Claude Code，并通过 SSH 远端转发网络 | [完整使用指南](docs/ai-cc.md) |
| `ai-claude` | 本地 Agent 通过 SSH 隧道调用远端 Claude 网关 | [使用与部署](docs/ai-claude.md) |
| `ai-remote` | 客户端不持有真实模型 Key，由远端服务代理并计量 | [服务器部署与运维](docs/ai-remote-server.md) |

`ai-cc` 的最小验证流程：

```bash
ai-cc --probe
ai-cc
```

`ai-cc` 镜像预装 `jq`、`file`、`zip`/`unzip`、bzip2/xz、procps、DNS 诊断工具、
SQLite CLI、FFmpeg、Python 数据工具以及 Playwright/Chromium。系统和 Python 直接
依赖分别由 [`deploy/ai-cc-apt-packages.txt`](deploy/ai-cc-apt-packages.txt) 与
[`deploy/ai-cc-python-packages.txt`](deploy/ai-cc-python-packages.txt) 维护；运行容器的
根文件系统为只读，需要长期使用的系统命令应加入清单并重建镜像。完整维护流程见
[`docs/ai-cc.md`](docs/ai-cc.md#镜像软件包清单与更新)。

`ai-claude` 默认连接 SSH 别名 `remote` 上的 `127.0.0.1:8791`：

```bash
ai-claude --probe
ai-claude ask "只回复 OK"
ai-claude --sandbox
```

`ai-remote` 客户端可从源码构建，也可以使用安装脚本：

```bash
npm run build:remote

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/lteu/agent/main/install.sh | sh

# Windows PowerShell
irm https://raw.githubusercontent.com/lteu/agent/main/install.ps1 | iex
```

默认通过 SSH 隧道连接别名 `remote`；相关覆盖项可运行各命令的 `--help` 查看。

## 日志与排障

项目默认把对话、轻量 Agent 生命周期、工具错误和崩溃信息写入仓库的 `log/` 目录；可用 `AI_LOG_DIR` 改到其他位置。常用文件包括：

- `log/agent-events.jsonl`：始终启用的轻量生命周期诊断。
- `log/chat-history.jsonl` 和 `log/chat-history.md`：各渠道问答记录。
- `log/tool-errors.jsonl`：工具层技术错误。
- `log/crash.log`：未捕获异常和最近输入事件。

需要完整模型请求时，在启动前设置 `TRACE=1`：

```bash
TRACE=1 ai
TRACE=1 ai-claude --sandbox
```

这会额外生成 `history-trace-full.jsonl`、`history-trace-summary.jsonl`，Remote Claude 还会生成 `remote-communication.jsonl`。完整追踪可能包含 API Key、对话上下文、工具参数、工具结果和文件内容，禁止提交或分享；整个 `log/` 已被 Git 忽略。
